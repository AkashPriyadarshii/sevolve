Architecture

The 6-Phase Evolution Loop

Your agent is both the subject and the executor. sevolve orchestrates the improvement loop outside the agent runtime so that every change is measurable, verifiable, and revertible.

STAGE 01 evals/

Task Sampling

Samples difficult seed tasks and synthetic edge-cases from the eval corpus without contaminating the held-out verification testbed.

INPUT: seed_tasks.jsonl · held_out: 40%
STAGE 02 traces/

Trace Capture

Records complete execution trajectories: prompt inputs, agent tool invocations, shell error codes, and final produced artifacts.

JSONL · timestamp · token count · cost
STAGE 03 engine/judge.py

Blind Grading

Hard mechanical test checks + isolated LLM-as-judge. Grader never sees proposed diffs, completely eliminating reward-hacking.

Read-only process · zero diff leakage
STAGE 04 engine/optimizer.py

Trace Reflection & Mutation

The optimizer reads the failure trace, diagnoses why the agent missed the mark, and generates candidate skill or prompt mutations.

Generates candidate variants A/B/C
STAGE 05 engine/gate.py

Mechanical Gate Verification

Runs candidate variants through size limit ceilings, regression checks, and hermetic tests. --ci skips humans, never gates.

GATES: Size · Regression · Coverage ≥ 80%
STAGE 06 artifacts/

Held-Out Promotion & PR

The top performing candidate on held-out evaluations is version-bumped and committed directly to git via an automated pull request.

OUTPUT: PR opened · report-*.md generated

      Safety Matrix
      
Built with Strict Mechanical Guarantees

      

        Self-evolving loops without constraints lead to reward hacking and capability collapse. sevolve enforces four hard architectural guarantees.
      

    

    
    

      

        
Evaluator Isolation

        
Graders run read-only in separate subprocesses. The judge never inspects the proposed mutation diff — only the final execution output.

      

      
      

        
Strict Held-Out Gain

        
Mutations are only promoted if the held-out evaluation score strictly increases. Zero redundant version churn allowed.

      

      
      

        
Mechanical Gate Floor

        
Passing --ci automates human approval but can NEVER bypass size limits, hermetic tests, or regression suites.

      

      
      

        
Git As Ground Truth

        
Every evolved prompt and skill is committed as a clean git artifact with full commit history. Instant rollback via git revert.
